# 머니러시 (moneyrush)

**큰 주제 하나**만 넣으면, AI가 웹 검색으로 그 주제의 **최신 정보**를 훑어
지금 사람들이 가장 많이 찾아볼 만한 글감을 골라, 애드센스 승인 기준을 지킨 글과 썸네일을 만들어
**워드프레스에 정한 개수만큼 임시저장**해 주는 로컬 대시보드입니다.

워드프레스 애드센스 승인글 자동화 [워프러시](https://github.com/jettyy/wordpress)에서
**주제를 정하는 방식만** 바꾼 것입니다. 글의 형식, 준수 규칙, 썸네일 만드는 방식,
워드프레스에 올리는 방법은 전부 그대로입니다.

| | 워프러시 | 머니러시 |
|---|---|---|
| 주제 | 엑셀에서 **사람이 붙여넣음** | 큰 주제 하나 → **AI가 최신 정보에서 골라옴** |
| 언제 끝나는가 | 붙여넣은 주제를 다 쓰면 | **정한 개수를 임시저장하면** |
| 주제가 떨어지면 | 끝 | **알아서 새로 찾아옴** |
| 여러 주제를 걸어두려면 | 한 번에 다 붙여넣기 | **한 번에 다 붙여넣기 (한 줄 = 주문 하나)** |
| 글 형식 · 썸네일 · 준수 검사 | — | **똑같습니다** |

- 주제 발굴: **웹 검색**으로 최신 정보를 훑고 관심도 점수를 매겨 고릅니다
- 글 생성: `claude -p` (Claude Code CLI 헤드리스 모드) → **구독 요금제 그대로 사용**, 토큰 종량 과금 없음
- 자료 조사: 고른 주제마다 **다시 웹 검색**으로 사실과 출처를 모아 그것만 근거로 씁니다
- 애드센스 준수: 분량·문체·표·구조를 **프로그램이 직접 검사**하고, 어긋나면 그 항목만 짚어 다시 쓰게 함
- 워드프레스 접속: **공식 REST API + 응용 프로그램 비밀번호**. 브라우저 로그인도, 화면 자동화도 없음
- 본문 형식: **구텐베르크 블록 마크업**. 문단·소제목·목록·표가 블록 에디터에서 그대로 편집됨
- 썸네일: HTML 단색 썸네일이 기본. 원하면 **이미지 API가 제목·띠·뱃지까지 통째로** 그립니다
- 발행은 하지 않습니다. **임시저장까지만** 하고, 사실 확인과 발행은 사람이 합니다.

## 어떻게 도는가

큰 주제와 개수를 넣고 **[확인]** 을 누르면 **대기열**에 들어갑니다.
누르는 즉시 입력칸이 비워지므로, 검색이 도는 동안에도 다음 주제를 계속 넣을 수 있습니다.

```
[확인] "전기차" 5건      ─┐
[확인] "청년 지원금" 3건  ├─ 대기열 (넣은 순서대로)
[확인] "부동산 정책" 5건  ─┘
        │
        ▼  실행기가 앞에서부터 하나씩 가져다 씁니다
┌─ 주문 "전기차" 5건 ────────────────────────────────────┐
│  ├─ [발굴]  웹 검색 7회 → 후보 8건 → 관심도 순으로 채택   │
│  │          "전기차 공공충전요금 8월부터 5단계로 개편…" 90점 │
│  │          "2026년이 마지막? 취득세·개소세 감면 일몰…"  87점 │
│  ├─ [조사]  주제마다 다시 검색해 사실·출처를 모음          │
│  ├─ [집필]  검색을 끄고 그 자료만 보고 씀 → 준수 검사      │
│  ├─ [썸네일] 제목·띠·뱃지가 들어간 그림                   │
│  └─ [저장]  워드프레스 **임시글**로. 발행하지 않음         │
│      └─ 5건이 저장될 때까지 반복. 주제가 떨어지면 다시 발굴 │
└────────────────────────────────────────────────────────┘
        │
        ▼  개수를 채우면 다음 주문으로
┌─ 주문 "청년 지원금" 3건 ─ ... ─┐
```

한 건이 실패하면 세지 않고 다음 주제로 넘어갑니다. **성공한 것만 개수에 셉니다.**
5건을 원했으면 워드프레스 임시글에 5건이 올라갑니다.

한 주문이 개수를 채우면 넉넉히 받아 둔 나머지 주제는 **건너뜀**으로 정리하고
다음 주문으로 넘어갑니다. 그래야 "5건만" 이라는 약속이 지켜집니다.

## 주제를 어떻게 고르는가

"최신 정보"만으로는 부족합니다. 어제 나온 뉴스라도 아무도 안 찾는 것이 있고,
사람들이 실제로 검색창에 치는 것은 따로 있습니다. 그래서 발굴 단계에서
**조회수가 나오는 조건**을 순서대로 일러 줍니다.

| 우선순위 | 어떤 것 |
|---|---|
| 1 | **지금 막 바뀐 것** — 제도 개편, 새 정책, 요금·금리 변동, 시행일이 정해진 것 |
| 2 | **내 돈·시간·자격이 걸린 것** — 신청 방법, 지원 대상, 지급액, 마감일, 과태료 |
| 3 | **검색창에 그대로 칠 만한 것** — 사람들이 입력할 말이 분명한 소재 |
| 4 | **아직 정리된 글이 적은 것** — 뉴스는 많은데 "그래서 어떻게 하냐" 가 없는 소재 |
| 5 | **기한이 임박한 것** — 이번 달, 이번 분기에 마감되거나 시작되는 것 |

반대로 고르지 못하게 막는 것도 있습니다. 하루 지나면 아무도 안 찾는 가십,
연예인 사생활, 정치적 진영 다툼, 확인되지 않은 의혹, **의료·금융에서 효과나 수익을
단정하는 소재**(애드센스 정책 위반), 검색으로 근거를 못 찾은 소재입니다.
마지막 항목이 중요합니다. 근거가 없는 주제는 집필 단계에서 어차피 거절당해
호출만 버리게 됩니다.

고른 주제에는 **0~100점의 관심도 점수**와 "지금 왜 이걸 찾는지" 한 줄이 붙습니다.
작업표의 **관심도** 열에 점수가 뜨고, 마우스를 올리면 이유와 검색어가 보입니다.

### 제목을 어떻게 쓰게 하는가

키워드가 아니라 **그대로 글 제목이 될 한 문장**으로 받습니다.

- 나쁜 예: `전기차 보조금`
- 좋은 예: `2026년 전기차 보조금, 지역별로 얼마나 달라졌을까`

항목을 나열하는 글이면 개수를 문장에 넣게 합니다(`TOP 5`, `7가지`).
개수가 들어가면 기존 규칙대로 항목마다 **상세 설명 · 자격 요건 · 활용 분야 ·
장단점 · 준비 팁**을 세부 소제목으로 나눠 씁니다.

`충격`, `경악`, `이것만 알면` 같은 낚시성 표현은 프롬프트로 막고, 그래도 나오면
**프로그램이 제목에서 걸러냅니다.** 승인 심사에서 감점되는 표현이기 때문입니다.

### 같은 주제를 두 번 쓰지 않습니다

큰 주제 하나로 며칠씩 계속 돌리는 도구라서, 이게 없으면 사흘째부터 비슷한 글만 나옵니다.

- 발굴한 주제는 `data/topic-history.json` 에 남고, 다음 발굴 프롬프트에 **"이건 이미 썼다"** 로 들어갑니다
- 작업 목록을 비워도 기록은 남습니다. 그래야 어제 쓴 주제를 오늘 다시 안 고릅니다
- 글쓰기가 실패한 주제도 기록합니다. 안 그러면 매번 같은 주제를 골라 와 매번 실패합니다
- 돌아온 목록 안에서도 겹치는 것을 버립니다. 비교할 때 **공백과 기호를 무시**해서
  `국가기술자격증 TOP 5!` 와 `국가기술자격증top5` 를 같은 것으로 봅니다
- 같은 제도라도 다른 각도(신청 방법 / 달라진 점 / 대상별 차이 / 흔한 실수)로 잡으라고 일러 줍니다

처음부터 다시 쓰고 싶으면 2번 칸의 **[발굴 기록 지우기]** 를 누르세요.

## 쓰는 법

1. **워드프레스 연결** — 사이트 주소, 사용자 이름, 응용 프로그램 비밀번호를 넣고 [연결 확인]
2. **큰 주제와 개수** — 2번 칸에 넣고 **[확인]** (Enter 키로도 됩니다)
3. **바로 다음 주제** — 칸이 비워져 있으니 이어서 넣으면 됩니다. 넣은 만큼 줄을 섭니다
4. **확인** — 워드프레스 글 목록의 **임시글**에서 내용과 사실관계를 확인하고 발행하세요

걸어둘 주제가 이미 정해져 있다면 **[여러 개 한 번에 붙여넣기]** 로 스무 개든 한꺼번에 넣습니다.
바로 아래 항목을 보세요.

[확인] 을 누르면 **실행도 같이 시작됩니다.** [실행] 버튼을 따로 누르지 않아도 됩니다.
(워드프레스 연결이 안 돼 있으면 대기열에만 넣어 두고, 연결한 뒤 [실행]을 누르면 이어서 돕니다)

### 대기열 지우기

대기열은 2번 칸 아래에 줄지어 보입니다. 한 줄씩 **[취소]** 로 뺄 수도 있지만,
스무 개를 걸어놓고 하나씩 누르는 건 일이라 목록 위에 일괄 버튼을 뒀습니다.

| 버튼 | 무엇을 지우나 |
|---|---|
| **끝난 주문 정리** | 완료·중단된 줄만. 표를 정리하는 용도라 되돌릴 게 없습니다 |
| **대기 중인 것 비우기** | 아직 시작 안 한 것만. **진행 중인 주문은 남깁니다** |
| **전체 비우기** | 전부. 진행 중인 것도 포함합니다 |

가운데 버튼이 "이번 것까지만 하고 그만" 할 때 쓰는 것입니다. 쓰고 있던 글까지
버리지 않고 남은 예약만 걷어냅니다.

지워진 주문이 데려온 **아직 안 쓴 주제도 같이 정리**됩니다. 주문만 지우면
주제가 작업 목록에 남아 계속 써지기 때문입니다. **이미 임시저장된 글은
워드프레스에 그대로 남습니다.** 지우는 것은 앞으로의 예약뿐입니다.

지울 것이 없는 버튼은 눌리지 않게 꺼 둡니다. 되돌릴 수 없는 두 버튼은 확인창을 띄웁니다.

> **처음 써 보신다면 [미리 보기만] 을 한 번 눌러보세요.** 대기열에 넣지 않고
> 어떤 글감이 나오는지만 보여줍니다. 큰 주제가 너무 넓거나 너무 좁으면 거기서 드러납니다.
> 넓으면 산만한 글감이 섞이고, 좁으면 금방 소재가 떨어집니다.

### 여러 개를 한 번에 붙여넣기

주제를 미리 적어 두셨다면 하나씩 [확인]을 누를 것 없이 **[여러 개 한 번에 붙여넣기]** 를
펼쳐 통째로 넣으면 됩니다. **한 줄이 주문 하나**입니다.

```
대학 입결 순위

대기업 평균 연봉 순위

전문직 소득 순위

공기업 연봉 순위
```

- 줄 사이에 **빈 줄이 있어도** 됩니다
- `- 대학 서열`, `1. 시가총액 순위` 처럼 **목록 기호나 번호가 붙어 있어도 알아서 떼어냅니다.**
  그대로 두면 큰 주제에 "1." 이 붙은 채로 검색됩니다
- 붙여넣기 안에서 **겹치는 줄은 버립니다.** 공백 차이도 같은 것으로 봅니다
- **이미 대기열에 있는 주제도 빼고 넣습니다.** 같은 목록을 두 번 붙여넣어도 두 배로 안 걸립니다
  (하나씩 [확인]으로 넣을 때는 "5편 더" 라는 뜻일 수 있어 막지 않습니다)
- 엑셀에서 **두 번째 열에 개수를 적어 두면** 그 줄만 그 개수로 들어갑니다
  (`대학 서열` <TAB> `3`)

> **숫자를 먼저 확인하세요.** 위 [임시저장할 개수]가 **모든 줄에 똑같이** 적용됩니다.
> 20줄에 10건이면 **글 200편**이고, 한 편에 4~5분이니 **15시간이 넘습니다.**
> 그래서 넣기 전에 몇 편이 걸리는지 세어서 확인창에 띄웁니다.

### 큰 주제는 얼마나 넓게

| 큰 주제 | 어떤가 |
|---|---|
| `정부 지원금` | 조금 넓습니다. 소재는 많지만 성격이 제각각이라 블로그 색이 흐려집니다 |
| `청년 정부 지원금` | **적당합니다.** 소재가 꾸준히 나오고 방향이 한결같습니다 |
| `2026년 청년월세지원 소득 기준` | 너무 좁습니다. 두세 편 쓰면 더 쓸 것이 없습니다 |

소재가 떨어지면 로그에 `새로 쓸 만한 주제를 찾지 못했습니다` 가 뜨고 **그 주문만** 접은 뒤
대기열의 다음 주문으로 넘어갑니다. 큰 주제를 조금 넓히거나, 관심도 점수 하한을 낮춰 보세요.

## 2번 칸 설정

| 항목 | 설명 |
|---|---|
| 큰 주제 | 이것만 넣으면 됩니다. 개별 글 제목을 적는 칸이 **아닙니다** |
| 임시저장할 개수 | 이만큼 **저장에 성공하면** 그 주문이 끝납니다. 실패·건너뜀은 세지 않습니다 |
| 한 번에 찾아올 주제 수 | 주제가 떨어질 때마다 이만큼씩. 발굴은 검색이 여러 번 도는 호출이라 몇 개씩 받는 편이 빠릅니다 |
| 최신 기준 (일) | 며칠 이내에 나온 정보를 우선할지. 기본 30일 |
| 관심도 점수 하한 | 이보다 낮은 주제는 버립니다. 기본 40. **주제를 못 찾으면 이 값을 낮추세요** |
| 발굴 검색 횟수 상한 | 한 번 발굴할 때 검색을 몇 번까지. 기본 6회 |

**여러 개 한 번에 붙여넣기**는 큰 주제를 줄 단위로 받아 주문을 한꺼번에 만듭니다. (위 참고)

**직접 주제 추가**를 펼치면 예전처럼 **개별 글 제목**을 직접 넣을 수도 있습니다.
두 칸을 헷갈리지 마세요. 위쪽은 한 줄이 **주문**(글 여러 편)이고, 이쪽은 한 줄이 **글 한 편**입니다.
꼭 쓰고 싶은 주제가 따로 있을 때 쓰세요. 직접 넣은 주제가 발굴한 주제보다 먼저 처리됩니다.

## 멈추지 않고, 그렇다고 영원히 돌지도 않게

자는 동안 돌려놓는 도구라 두 가지가 다 위험합니다. 세 번째 주제에서 멈춰 있는 것도,
아무것도 저장 안 되는데 검색만 계속 태우는 것도 곤란합니다.

| 무슨 일 | 어떻게 |
|---|---|
| **AI가 주제를 거절** | **건너뜀**으로 표시하고 바로 다음 주제로. 재시도하지 않습니다 |
| 그 밖의 실패 | 설정한 횟수만큼 재시도한 뒤 **실패**로 두고 다음 주제로 |
| 사용량 한도 | 여기서만 **일시정지**합니다. 계속 돌려봐야 전부 실패하기 때문입니다 |
| **주제를 못 찾음** | 두 번 연달아 빈손이면 **그 주문만** 접고 다음 주문으로 갑니다 |
| **찾아오는데 저장이 안 됨** | 목표의 두 배 넘게 찾아왔는데 저장이 안 되면 그 주문을 포기합니다 |

뒤의 두 항목이 이 프로그램에만 있는 장치입니다. 목표를 채울 때까지 도는 구조라서,
워드프레스가 내려가 글이 전부 실패하면 "찾아오고 → 실패하고 → 다시 찾아오고" 를
끝없이 반복하게 됩니다. 주제만 늘고 글은 하나도 안 늘어나는 상태라 거기서 멈춥니다.

**멈추는 단위는 대기열 전체가 아니라 주문 하나입니다.** 소재가 떨어진 주제 하나 때문에
뒤에 줄 서 있는 다른 주제까지 세워두면 밤새 돌려놓은 의미가 없기 때문입니다.

## 자료 조사 (웹 검색)

주제를 고른 뒤에도 글을 쓰기 전에 **주제마다 다시 검색**합니다. 발굴 단계의 검색은
"무엇에 대해 쓸지" 를 정하려는 것이고, 여기 검색은 "그 글에 무슨 수치를 넣을지" 를
정하려는 것이라 목적이 다릅니다.

**조사와 집필을 두 번의 호출로 나눕니다.**

1. **조사** — 검색 도구를 켜고 사실과 출처 URL 만 모읍니다 (글은 쓰지 않습니다)
2. **집필** — 검색 도구를 끄고, 모아온 자료만 보고 글을 씁니다

한 번에 시키지 않는 이유가 있습니다. 도구를 쓰면서 동시에 엄격한 JSON 을 뱉게 하면
검색 결과를 설명하는 산문이 앞뒤로 붙어 파싱이 자주 깨집니다.
나눠서 얻는 것이 하나 더 있습니다. 조사 결과가 `research.json` 으로 남아서
발행 전에 **이 글이 무엇을 근거로 쓰였는지** 사람이 직접 확인할 수 있습니다.

조사 단계에서 챙기는 것들:

- 오늘 날짜를 알려줘 "최신"의 기준을 잡습니다
- 공식 출처(정부기관, 공공기관, 주관 기관)를 민간 블로그보다 우선합니다
- 중요한 수치는 두 곳 이상에서 교차 확인하게 합니다
- **지어낸 URL 을 걸러냅니다.** `example.com` 이나 점 없는 호스트는 버립니다
- 확인하지 못한 내용은 `unverified` 로 따로 받아, 본문에서 단정하지 않게 합니다
- **검색이 실제로 몇 번 돌았는지 셉니다.** 0회면 "검색했다고 말만 한" 결과라서 경고를 띄웁니다

마지막 항목은 발굴 단계에도 똑같이 있습니다. 검색 0회로 고른 주제는 최신 정보가
아니라 모델이 아는 내용이라, 이 도구의 목적 자체가 무너집니다.

> **비용과 시간이 늡니다.** 글 하나에 조사 1회 + 집필 1회, 여기에 주제 발굴이
> 몇 건에 한 번씩 붙습니다. 글 하나에 3~5분 잡으시면 됩니다.

> **조사해 왔다고 사실이 보장되지는 않습니다.** 검색 결과에도 틀린 내용이 있고,
> 모델이 자료를 잘못 읽을 수도 있습니다. 그래서 이 프로그램은 발행하지 않고 임시저장만 합니다.
> 미리보기 맨 위의 **확인하지 못한 내용**부터 보시고, 수치는 원문에서 대조하세요.

## 애드센스 승인 규칙을 어떻게 지키는가

여기서부터는 워프러시와 **완전히 같습니다.** 규칙을 프롬프트에 적어 넣는 것만으로는
부족합니다. 모델이 안 지킨 채로 나와도 그대로 저장되기 때문입니다.

그래서 `src/content/adsense.js` 한 곳에 규칙을 정의하고, **같은 정의에서 두 가지를 만들어 냅니다.**

1. 글을 쓰기 전 프롬프트에 들어갈 **지시문**
2. 나온 글을 실제로 검사하는 **검사기**

검사에 걸리면 걸린 항목만 짚어 다시 쓰게 하고(기본 1회), 통과할 때까지 확인합니다.
지시와 검사가 한 파일에 묶여 있어서 따로 놀 수가 없습니다.

| 규칙 | 검사 내용 |
|---|---|
| 분량 | 공백 제외 1,800자 이상 (설정에서 조정) |
| 종결어미 | `~습니다`, `~입니다` 형태가 85% 이상. `~함`, `~임` 개조식은 발견 즉시 실패 |
| 소제목 구조 | H2 3개 이상 + H3 1개 이상. 본문에 H1 금지 |
| 선정 기준 | 서두에 "무엇을 기준으로 골랐는지" 단락이 있는지 |
| 비교 표 | 2행 2열 이상의 표가 최소 1개 |
| 불렛 포인트 | 목록이 최소 1개 |
| 항목별 상세 | 항목형 글에서 각 항목마다 세부 소제목 3개 이상 |
| 서두 인사말 금지 | "안녕하세요", "이번 포스팅에서는" 으로 시작하지 않는지 |
| 기호·이모지 | 별표, 화살표, 이모지 등 장식 기호가 본문에 있는지 |
| 마무리 | 요약과 독려가 담긴 마무리 단락이 충분한지 |

결과는 작업표의 **준수** 열에 `10/10` 처럼 표시되고, 마우스를 올리면 항목별 판정이 보입니다.
`설정 > 끝내 못 고치면 저장하지 않기` 를 켜면 규칙을 못 지킨 글은 아예 올리지 않습니다.

> 검사기는 형식을 봅니다. **사실관계는 사람이 확인해야 합니다.**

## 주제에 따라 글 모양이 달라집니다

| 주제 예시 | 모양 | 어떻게 쓰는가 | 호출 횟수 |
|---|---|---|---|
| `국가기술자격증 TOP 5` | 항목별 상세형 | 항목마다 H2 섹션 1개 + H3 세부 소제목 5개 | 1회 |
| `겨울 캠핑 장비 추천` | 항목별 상세형 | 개수는 AI가 정합니다 (5개 내외) | 1회 |
| `전국 대학교 순위` | 대형 비교표형 | **개수를 안 써도 100위까지** 뽑습니다 | 3회 |
| `전세 계약 전 확인할 서류` | 정보 정리형 | H2 소제목 중심 + H3 세부 소제목 | 1회 |

13개 이상이면 항목마다 다섯 항목씩 쓰는 것이 현실적으로 불가능해서 표 중심으로 넘어갑니다.
순위 글을 100위까지 채우는 방법, 뒤 구간을 지방·소규모까지 넓히는 지시,
중복 이름을 버리고 빠진 번호를 다시 채우는 부분은 워프러시와 같습니다.

## 썸네일 (선택)

기본값은 **HTML로 만드는 단색 썸네일**입니다. 추가 비용이 없습니다.
이미지 생성 API 를 붙이면 두 가지 방식 중에 고를 수 있습니다.

| 방식 | 어떻게 | 한글 |
|---|---|---|
| **통째로 그리기** (`full`, 기본) | 제목·띠·뱃지까지 그림 안에 다 그립니다 | 이미지 모델이 그립니다. 가끔 뭉개집니다 |
| **배경만 그리기** (`overlay`) | 글자 없는 배경만 그리고 한글은 HTML 이 얹습니다 | 브라우저가 그려서 **절대 안 깨집니다** |

두 방식 모두 **가장 싼 모델부터** 씁니다. 만들고 나서 글자가 제대로 나왔는지 확인하고,
실제로 깨졌을 때만 한 단계 올라갑니다.

```
1) 가장 싼 모델로 그린다  →  글자 확인 통과  →  끝            ← 대부분 여기서 끝납니다
2) 깨졌으면 같은(가장 싼) 모델로 한 번 더                       ← 그냥 운이 나빴을 수 있습니다
3) 그래도 깨지면 다음으로 싼 모델로 한 번                       ← 이 모델이 한글을 못 그리는 것입니다
4) 그래도 깨지면 HTML 썸네일                                    ← 한글이 절대 안 깨집니다
```

[aistudio.google.com](https://aistudio.google.com/apikey) 에서 키를 발급받아
**6번 설정**에 넣고 **[이미지 API 테스트]** 를 누르면 실제 문구가 박힌 그림 한 장과
모델 목록이 나옵니다. 가장 싼 등급 기준 장당 $0.03 안팎입니다.

## 응용 프로그램 비밀번호 발급

로그인 비밀번호가 **아닙니다.** 이 프로그램만 쓸 수 있는 별도의 열쇠이고, 언제든 따로 폐기할 수 있습니다.

1. 워드프레스 관리자 → **사용자 → 프로필**
2. 아래로 내려 **응용 프로그램 비밀번호** 칸
3. 이름을 아무거나 적고 (예: `moneyrush`) **[새 응용 프로그램 비밀번호 추가]**
4. `xxxx xxxx xxxx xxxx xxxx xxxx` 형태의 비밀번호가 **한 번만** 표시됩니다. 그대로 복사
5. 대시보드 1번 칸에 사이트 주소 · 사용자 이름과 함께 넣고 **[연결 확인]**

칸이 보이지 않는다면 사이트가 http 이거나, 보안 플러그인이 기능을 꺼둔 경우입니다.

| 썸네일 스타일 / 크기 | `auto`(AI 선택) · `minimal`(권장) · `bold` · `gradient` · `editorial` |
| 글 사이 대기 | 기본 20~60초 무작위. 호스팅의 요청 제한을 피합니다 |
| 재시도 횟수 | 실패한 주제를 자동으로 다시 시도하는 횟수 |
| 연속 실패 시 멈춤 | **0이면 멈추지 않고 끝까지** 갑니다 (기본) |

설정 파일에서만 조정 가능한 항목:

- `discover.region` — 어느 지역 독자 기준으로 찾을지 (기본 `한국`)
- `discover.timeoutMs` — 발굴 대기 시간 (기본 420초)
- `claude.command` — `claude` 실행 파일 경로 (PATH에 없을 때)
- `claude.timeoutMs` — AI 응답 대기 시간 (기본 420초)
- `run.chromiumPath` — 썸네일 렌더링에 쓸 크롬/크로미움 경로 (환경변수 `CHROMIUM_PATH` 도 가능)
- `image.timeoutMs` — 이미지 생성 대기 시간 (기본 120초)

## 추가 지침 · 참고 예시

3번 칸의 **추가 지침**은 프롬프트의 맨 앞과 맨 끝에 두 번 들어갑니다.
한 줄에 하나씩 쓰면 더 잘 지킵니다.

```
수도권 기준으로 설명할 것
비용은 대략적인 범위로만 언급할 것
마지막에 준비 체크리스트를 넣을 것
```

**애드센스 필수 준수 규칙이 지침보다 우선**합니다. "세 줄로 짧게 써줘" 같은 지침이
규칙을 이겨버리면 이 프로그램의 존재 이유가 사라지기 때문입니다.

**참고 예시 글**을 올리면 AI 가 문체·문단 길이·소제목 방식을 참고합니다.
내용을 베끼지는 않고, 애드센스 규칙과 충돌하면 규칙을 따릅니다.

## 실행이 자꾸 실패할 때

먼저 **설정 → [선택한 모델로 연결 테스트]**, **1번 칸 → [연결 확인]**,
**2번 칸 → [주제 찾아보기]** 를 눌러보세요. 세 가지 연결이 다 살아 있는지 한 번에 확인됩니다.

| 증상 | 원인과 해결 |
|---|---|
| `웹 검색이 실제로 실행되지 않았습니다 (검색 0회)` | 검색 없이 답만 온 경우입니다. **이 도구는 검색이 핵심이라 여기서 먼저 해결해야 합니다.** `claude` CLI 를 최신 버전으로 올리고 구독 플랜에서 웹 검색을 쓸 수 있는지 확인하세요 |
| `새로 쓸 만한 주제를 찾지 못했습니다` | 큰 주제가 너무 좁거나 소재를 다 썼습니다. 큰 주제를 넓히거나 관심도 점수 하한을 낮추세요. 정말 다 썼다면 [발굴 기록 지우기] |
| `두 번 연속으로 새 주제를 찾지 못해 이 주문을 접습니다` | 위와 같습니다. 그 주문만 접고 다음 주문으로 넘어갑니다 |
| `주제를 N건이나 찾았는데 임시저장된 글은 M건뿐` | 글쓰기나 저장 쪽이 계속 실패하고 있습니다. 작업표의 실패 메시지를 먼저 보세요 |
| [확인]을 눌렀는데 시작이 안 됨 | 워드프레스 연결이 먼저입니다. 대기열에는 들어가 있으니 연결한 뒤 [실행]을 누르면 이어서 돕니다 |
| 비슷한 글이 계속 나옴 | 큰 주제가 좁아 소재가 겹치는 경우입니다. 큰 주제를 넓히거나 며칠 간격을 두고 돌리세요 |
| `인증에 실패했습니다 (401)` | 사용자 이름이나 응용 프로그램 비밀번호가 틀렸습니다. 일부 호스팅은 `Authorization` 헤더를 지우므로, 그 경우 `.htaccess` 에 `SetEnvIf Authorization "(.*)" HTTP_AUTHORIZATION=$1` 을 추가해야 합니다 |
| `권한이 없습니다 (403)` | 그 계정에 글쓰기 권한이 없습니다. 기여자 이상 권한이 필요합니다 |
| `REST API 경로를 찾지 못했습니다 (404)` | 주소가 틀렸거나 REST API 를 막는 플러그인이 있습니다 |
| `모델을 쓸 수 없는 플랜일 수 있습니다` | 구독 플랜에서 그 모델을 못 씁니다. Sonnet 5 나 기본값으로 바꾸세요 |
| `사용량 한도에 걸린 것 같습니다` | 자동으로 일시정지되니 잠시 뒤 [이어서 실행]을 누르세요 |
| `claude CLI 를 찾을 수 없습니다` | `npm install -g @anthropic-ai/claude-code` 후 `claude` 로 한 번 로그인하세요 |
| `AI가 이 주제를 거절했습니다` | 그 주제로는 사실이 아닌 내용을 지어내야 하는 경우입니다. **건너뜀**으로 표시하고 다음 주제로 넘어갑니다 |
| 준수 검사를 계속 통과 못 함 | 최소 분량을 낮추거나 모델을 Opus 5 로 올려보세요 |
| 썸네일 한글이 깨짐 | 설정에서 **배경만 그리기**로 바꾸세요 (한글이 절대 안 깨집니다) |
| `Cannot find package 'express'` | `npm install` 을 아직 안 하셨습니다 |
| `PORT=3001 : 용어가 인식되지 않습니다` | PowerShell 에는 그 문법이 없습니다. `$env:PORT=3001` 을 먼저 치세요 |

오류 원문은 `data/logs/claude-fail-*.log` 에, 서버 로그는 `data/logs/server-*.log` 에 남습니다.

## 안전장치

- **발행하지 않습니다.** `createDraft()` 는 `status` 가 `draft` 가 아니면 요청 자체를 거부합니다.
- **비밀번호를 밖으로 내보내지 않습니다.** `data/settings.json`(권한 600)에만 저장되고,
  대시보드로 내려보내는 설정에서는 값을 빼고 "채워짐" 여부만 보냅니다.
- **본문에 태그를 주입할 수 없습니다.** AI 응답은 전부 이스케이프하고 `<b>` 강조만 되살립니다.
  발굴해 온 주제와 근거 주소도 마찬가지로, 화면에 그릴 때 전부 이스케이프합니다.
- **끝없이 돌지 않습니다.** 주제를 못 찾거나, 찾아와도 저장이 안 되면 멈춥니다.

## 알아두실 점

- 발행이 아니라 **임시저장**만 합니다. 글의 사실관계와 최종 품질은 사람이 확인하고 발행하세요.
  **주제를 AI가 골랐다고 해서 확인을 덜 해도 되는 것이 아닙니다.** 오히려 더 봐야 합니다.
- 애드센스 승인은 글 품질만으로 결정되지 않습니다. 사이트 연령, 필수 페이지(개인정보처리방침,
  문의), 글 개수, 방문자 유입 등도 함께 봅니다. 이 프로그램은 그중 **글 품질 부분**을 돕습니다.
- 짧은 시간에 많은 글을 자동으로 올리면 호스팅의 요청 제한에 걸릴 수 있습니다.
  기본 대기 시간(20~60초)을 너무 줄이지 마세요.
- 관심도 점수는 **AI가 매긴 추정치**입니다. 실제 검색량 데이터가 아닙니다.
  주제를 고르는 순서를 정하는 용도로만 쓰세요.
